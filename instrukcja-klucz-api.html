Klucz API do funkcji AI — instrukcja krok po kroku

IdeaTree · jak zdobyć klucz OpenAI lub Anthropic i dodać go w aplikacji

Funkcje AI — rozwijanie pomysłów i sugestie zadań TODO — pojawią się w kolejnej wersji IdeaTree. Klucz możesz przygotować już teraz. Jest zapisywany tylko na Twoim urządzeniu (komputer, telefon lub przeglądarka), nie trafia do kopii zapasowych JSON i nie jest nigdzie wysyłany.

OpenAI (modele GPT)

  1. Wejdź na platform.openai.com i zaloguj się (albo załóż konto).
  2. W ustawieniach konta otwórz Billing i dodaj środki. API jest rozliczane za zużycie — osobno od subskrypcji ChatGPT.
  3. Przejdź do sekcji API keys i kliknij Create new secret key.
  4. Nadaj nazwę, np. IdeaTree, utwórz klucz i od razu go skopiuj (zaczyna się od sk-). Po zamknięciu okna nie zobaczysz go ponownie.

Anthropic (modele Claude)

  1. Wejdź do konsoli Anthropic: console.anthropic.com i zaloguj się.
  2. W Settings → Billing dodaj środki. API jest rozliczane za zużycie — osobno od planów Claude.ai.
  3. Otwórz Settings → API Keys i kliknij Create Key.
  4. Nadaj nazwę i skopiuj klucz (zaczyna się od sk-ant-).

Dodanie klucza w IdeaTree

  1. Kliknij „⋯” na górnym pasku i wybierz Ustawienia lokalne — albo w notatce kliknij AI · Wkrótce, a potem Przejdź do Ustawień.
  2. W sekcji Klucz API wybierz dostawcę: OpenAI albo Anthropic.
  3. Wklej klucz w pole i kliknij Zapisz klucz. Gotowe — funkcje AI użyją go, gdy pojawią się w aplikacji.

Bezpieczeństwo klucza

  • Traktuj klucz jak hasło — nie wysyłaj go nikomu i nie wklejaj na stronach, którym nie ufasz.
  • W panelu dostawcy ustaw miesięczny limit wydatków.
  • Klucz jest przechowywany w danych aplikacji bez szyfrowania — nie zapisuj go na urządzeniu, z którego korzystają inne osoby.
  • Jeśli klucz wycieknie, usuń go w panelu dostawcy, utwórz nowy, a w IdeaTree kliknij Usuń klucz i zapisz nowy.
